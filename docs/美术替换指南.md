# 美术素材替换指南

本文说明角色、敌人、地图瓦片、UI 皮肤当前是怎么画出来的，以及要换正式美术时改哪里。

> 约定：所有素材路径使用 `res://` 前缀。素材放入 `assets/` 下对应子目录后，Godot 会自动生成 `.import` 文件，直接引用即可。按 `AGENTS.md` 素材规则，优先 CC0 素材（Kenney 等）并保留各素材包的 `License.txt`。

---

## 一、角色（玩家）

**当前实现**：玩家没有贴图，是用代码画出来的。

文件：[scripts/player/player.gd](scripts/player/player.gd) 的 `_draw()` 函数（约 110 行起）：

```gdscript
func _draw() -> void:
    var color: Color = CLASS_COLORS.get(str(GameState.run_info.get("character", "warrior")), CLASS_COLORS["warrior"])
    draw_circle(Vector2.ZERO, 16.0, color)          # 身体圆
    draw_arc(Vector2.ZERO, 16.0, 0.0, TAU, 32, color.lightened(0.35), 2.0)  # 描边
    draw_line(Vector2.ZERO, _facing * 30.0, Color(0.95, 0.95, 0.9), 3.0)     # 朝向线
```

`CLASS_COLORS` 常量（文件顶部）定义了五个职业的占位色：
`warrior`/`mage`/`hunter`/`judge`/`monk`。

**换成贴图的步骤**：

1. 准备角色精灵图（建议 32×32 或 64×64，透明背景 PNG），放入例如 `assets/player/`。
2. 在 [scenes/player.tscn](scenes/player.tscn) 里给 `Player` 节点加一个子节点：
   - `Sprite2D`（静态图），或 `AnimatedSprite2D`（带动画，推荐正式版）。
3. 把贴图赋给该节点的 `texture`（Sprite2D）或 `SpriteFrames`（AnimatedSprite2D）。
4. 删掉 `_draw()` 函数里的 `draw_circle` / `draw_arc` / `draw_line`（或整个 `_draw()`）。

朝向：正式版若用 `AnimatedSprite2D`，可在 `_physics_process` 里根据 `_facing`（`Vector2.UP/DOWN/LEFT/RIGHT`）切换动画或翻转 `flip_h`，替换掉当前的朝向线。

## 二、敌人

**当前实现**：两种敌人也都是代码画圆。

- 追踪敌人：[scripts/enemies/chaser_enemy.gd](scripts/enemies/chaser_enemy.gd) 的 `_draw()`（61 行起）
- 木桩敌人：[scripts/enemies/dummy_enemy.gd](scripts/enemies/dummy_enemy.gd) 的 `_draw()`（53 行起）

换成贴图的方法和角色一样：在对应 `.tscn`（`scenes/dungeon/chaser_enemy.tscn`、`scenes/enemies/dummy_enemy.tscn`）里加 `Sprite2D`/`AnimatedSprite2D` 子节点并设贴图，然后删掉 `_draw()`。

## 三、地图瓦片

**当前实现**：瓦片集不是在编辑器里手搭的，而是 [rooms/base/tileset_factory.gd](rooms/base/tileset_factory.gd) 在运行时用代码从精灵表构建出来的。

关键常量（都在 `tileset_factory.gd` 顶部）：

| 常量 | 含义 | 当前值 |
|---|---|---|
| `SHEET_PATH` | 精灵表路径 | `res://assets/roguelike-rpg-pack/Spritesheet/roguelikeSheet_transparent.png` |
| `SOURCE_TILE` | 源精灵表瓦片尺寸 | 16 |
| `SOURCE_STEP` | 瓦片间距（含 1px 缝隙） | 17 |
| `TILE_SIZE` | 世界瓦片尺寸 | **64**（已改为 64×64） |
| `TILE_FLOOR_A` / `TILE_FLOOR_B` | 地板两种纹理的格坐标 | `(33,4)` / `(12,0)` |
| `TILE_WALL` | 墙（带碰撞） | `(36,1)` |
| `TILE_BAR` | 铁栅栏（带碰撞） | `(51,16)` |
| `TILE_GRASS` | 草地（4 种随机） | `(0,16)` 等 4 个 |

**瓦片尺寸说明**：源精灵表 `roguelikeSheet_transparent.png` 是 968×526 的 16×16 小瓦片（每格间 1px 缝隙）。`tileset_factory.gd` 会先剥离缝隙、再用最近邻放大到 64×64，所以世界瓦片现在是**原生 64×64**，`TileMapLayer` 的 scale 已是 1（不再是旧的 scale=4）。

**换地图素材的两种方式**：

### 方式 A：换一整张精灵表（最简单）

如果你有一套新的 64×64 瓦片集：

1. 把新图放进 `assets/` 下，例如 `assets/my_tileset.png`。
2. 如果新图是**原生 64×64 瓦片、无缝隙**，改 `tileset_factory.gd`：
   - `SHEET_PATH` 指向新图
   - `SOURCE_TILE = 64`、`SOURCE_STEP = 64`（无缝隙时等于瓦片尺寸）
   - 保持 `TILE_SIZE = 64`
   - 按新图里的实际位置改 `TILE_FLOOR_A` / `TILE_WALL` 等格坐标
3. 如果新图仍是 16×16 带缝隙，保持现有参数不变，只改 `SHEET_PATH` 和格坐标。

> 现成的 64×64 参考：`assets/roguelike-rpg-pack/Spritesheet/第一层1.png`（1536×1024，即 24×16 个 64px 格）。用它替换前需要先在图像编辑器里确认哪几格是地板、墙、门、草，再把对应格坐标填进 `TILE_FLOOR_A` / `TILE_WALL` / `TILE_GRASS` 等常量。

### 方式 B：逐瓦片微调（只换某一种纹理）

不想换整张图，只想把"墙"换成另一种纹理：直接在 `tileset_factory.gd` 里改对应的格坐标常量即可（例如 `TILE_WALL := Vector2i(x, y)`）。

**格坐标怎么确定**：用图像编辑器（如 Aseprite、GIMP、Krita）打开精灵表，从左上角 (0,0) 开始数，第 x 列第 y 行就是 `Vector2i(x, y)`。注意：瓦片之间有 1px 缝隙时，每个格实际占 17px（16 瓦片 + 1 缝隙），数格而不是数像素。

**房间布局**：地图布局本身（房间大小、门宽、墙厚）是代码常量，不是美术。见 [rooms/base/room_base.gd](rooms/base/room_base.gd) 的 `WORLD_TILE = 64` 与房间模板的 `room_width`/`room_height`（在 [rooms/layer_01/normal/layer1_room_template.gd](rooms/layer_01/normal/layer1_room_template.gd) 和 [rooms/layer_01/start_room.gd](rooms/layer_01/start_room.gd)）。换美术不影响这些数值。

## 四、UI 皮肤（按钮 / 面板 / 背景）

**当前实现**：UI 主题在 [scripts/ui/menu/ui_theme.gd](scripts/ui/menu/ui_theme.gd) 里用代码构建。

关键常量：

| 常量 | 用途 | 当前路径 |
|---|---|---|
| `BUTTON_TEX` | 按钮皮肤 | `res://assets/ui-pack/PNG/Blue/Default/button_round_depth_gradient.png` |
| `PANEL_TEX` | 面板边框 | `res://assets/fantasy-ui-borders/PNG/Default/Border/panel-border-000.png` |
| `MENU_BG` | 主菜单背景 | `res://assets/roguelike-rpg-pack/Sample2.png` |

换皮肤：把新图放进 `assets/`，改对应常量路径即可。注意 `ui_theme.gd` 里的 `texture_margin_*` / `content_margin_*` 是九宫格切边参数，换图后如果边框厚度不同，需要相应调整这些数值（否则按钮/面板会被拉伸变形）。

> 注意：主菜单的**角色选择按钮**在 [scripts/ui/menu/main_menu_controller.gd](scripts/ui/menu/main_menu_controller.gd)（`_build_new_game_panel` 里）单独硬编码了按钮皮肤 `res://assets/ui-pack/PNG/Blue/Default/button_round_depth_gradient.png`，换皮肤时这里也要一起改。
