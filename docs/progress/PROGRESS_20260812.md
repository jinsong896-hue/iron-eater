## 三、异常记录

| 现象 | 原因 | 解决方案/状态 |
|---|---|---|
| NavigationRegion2D 静态碰撞体解析后顶点为 0 | Godot 4.7 该解析路径在 headless 下未产出结果 | 改用手工构建导航多边形（房间可用区 + 门洞桥接 + 走廊），已解决 |
| GDScript 多行 lambda 括号解析报错（3 处） | lambda 闭括号与语句同行导致解析失败 | 改为具名辅助函数，已解决 |
| EquipmentInstance ID 同一秒生成重复 | ID 仅用模板 id + 秒级时间戳 | 改为 ticks_usec + 随机后缀，已解决 |
| 装备序列化丢失已装备 | 序列化只含背包 | 改为全量物品 + 槽位映射 + 反序列化时区分，已解决 |
| Variant 值 `:=` 推断警告被当作错误 | GDScript 严格模式 | 全部显式类型标注，已解决 |
| 测试计数函数按值传参导致误报 | 整型参数按值传递 | 改为成员计数，已解决 |
| NavigationRegion 同步出现 4~6 处边合并警告 | 手工构建导航多边形在门洞桥接/走廊相接处边过密 | 不影响寻路与玩法；列入 P2 打磨（合并走廊多边形） |
| 瓦片集 `Cannot create tile` | 精灵表末行网格不完整导致草瓦片坐标越界 | 改用有效坐标并加越界保护，已解决 |
| TileSet 碰撞层越界报错 | 未先添加物理层 | `add_physics_layer()`，已解决 |
