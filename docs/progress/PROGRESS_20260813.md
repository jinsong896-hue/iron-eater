## 三、异常记录

| 现象 | 原因 | 解决方案/状态 |
|---|---|---|
| `GameCatalog.get_class` 解析失败 | 与 Object 内置 `get_class()` 重名 | 改名 `class_info/difficulty_info/mode_info`，已解决 |

| 第一层 2×2 房间补建越界 | `_ensure_min_rooms` 未检查母网格边界 | 增加 [-half, half] 边界过滤，已解决 |
| 导航网格边合并警告（4~6 处） | 手工导航多边形门洞处边过密 | 不影响寻路，列入 P2 打磨 |
| 集成测试首次运行无输出挂起 | 场景脚本误用 SceneTree 的 `root` | 改为 `get_tree().root`，已解决 |
| 主菜单面板不可见、无法交互 | `_menu_panel()` 用默认节点名注册，`_show_state` 找不到面板 | 显式命名注册；新增交互测试，已解决 |
| 空存档卡无法创建 | 空槽的“进入”按钮被隐藏 | 空槽显示“＋ 创建存档”，已解决 |
