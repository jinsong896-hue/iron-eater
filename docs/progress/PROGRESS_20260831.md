# 《噬铁者》开发进度 · 2026-08-31

## 一、今日完成条目

### 0f. 修复完整地牢房间流程（两处断链）

- **问题 1——门收集失效**：RoomController 找门用的是「房间根直接子节点」，
  但门实际建在 `Room_N/Doors/` 容器下（`Door_*` 命名）→ 控制器永远收集 0 个门，
  锁门/开门对所有房间无效。修正为从 Doors 容器收集。
- **问题 2——门方向为空**：DoorBuilder 从未给 DoorTrigger 写 `direction`，
  玩家穿门时 `door_opened` 信号发空字符串 → GameRoot 按方向找邻接房间永远失败，
  **穿门不切房**。修正：建门时写入方向。
- **问题 3——切房后玩家落点**：普通房 JSON 无 player_spawn 标记，玩家切房后
  fallback 到硬编码 (15,0,15) 可能卡墙。修正：`_place_player(enter_direction)`
  按进入方向放在入口门内侧 1.5m（北门进→南侧内侧）；无门房间居中。
- 顺手发现（未修，数据小瑕疵）：room_start.json 有两条 east 门数据（重复 id），
  生成时第三个门节点带 @ 后缀；不影响流程。
- 固化 `tests/test_room_flow.tscn`（13 项）作为房间流程回归：进战斗房 → 锁门 →
  刷怪 → 清怪 → 开门 → 穿门切房 → 新房加载。
- 验证证据：七套测试全绿（framework 75 / room_flow 13 / combat 17 / floor 10 /
  death 6 / backpack 25 / menu 20），main.tscn headless 零错误

  范围均递增，第 4 段大击退）；连击窗口 0.45s（ASPD 缩放）；输入缓存 0.2s。

  - 21 项单测（推进/超时/特殊攻击接入点/动作锁）
- **玩家攻击重构**（`player.gd`）：

  - **奔跑攻击**（Shift+方向键）：150% 矩形冲撞 3m，消耗冲刺惯性
  - **跳跃攻击**（空格+方向键，0.18s 组合窗）：方案C——后跳蓄力 0.15s →
    俯冲 4m/0.2s（无敌帧）→ 落地 AOE 半径 3m + 170% 伤害 + 大击退
  - ASPD 缩冷却；攻击动作期间移动减速 50%；击退力写入敌人 velocity
  - 命中才计连击数（2 秒无命中清零）
- **HUD 连击数**：TopLeft 加 ComboLabel，连击 ≥2 显示"连击 xN"
- 新增 `tests/test_combat_system.tscn`（17 项）：四段参数递增校验、扇形命中/
  背后不命中、普攻4 远距大伤害、跳跃攻击三阶段全程（后跳→俯冲位移→落地AOE
  命中）、奔跑攻击冲撞判定与位移
