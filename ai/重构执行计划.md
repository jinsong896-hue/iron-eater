## 全局纪律（每个提交都适用，不再重复写）

1. **验证协议**：`bash tests/run_all.sh` 必须 23 套全绿 + 明确输出 `PASSED`。
   快速回路（单个套件，约 15–40 秒）：
   ```bash
   GODOT="F:/Godot_v4.7.2-stable_win64.exe/Godot_v4.7.2-stable_win64_console.exe"
   "$GODOT" --headless --path . res://tests/test_combat_system.tscn
   ```
2. **一提交一组件**：`refactor(<域>): 拆出 <组件>（行为零变化）`。提交前
   `git status` 核对只含预期文件；绿了才提交，红了就地修，不带病前进。
3. **回滚点**：任何提交红了修不动，`git reset --hard HEAD` 回到上一个绿提交
   （每提交都是绿的，所以永远有干净回滚点）。**禁止跨提交攒改动。**
4. **行号漂移**：每搬一批函数后，后续函数行号会变。执行时用
   `grep -n "^func <名>" <文件>` 现场定位，本计划的行号只是"当前长这样"。
5. **搬移规则**：函数体**逐字搬运**，只改三样——
   ①前缀 `_xxx` 变组件方法名；②对 player 字段的访问变 `player.xxx`
   （或构造时注入的 owner 引用）；③新增 `## 注释`（所有函数必须带注释，
   项目铁律）。**禁止顺手重写逻辑**——哪怕看着不顺眼。
