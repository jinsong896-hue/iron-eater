# IronEater Creator 技能参考手册

## 三、架构与设计模式

### component-system
- **用途**：ECS 组件模式——Entity 挂载可复用 Component
- **适用场景**：角色/怪物/物品统一用 Component 组合，避免深层继承

### dependency-injection
- **用途**：依赖注入——Autoload、export、场景注入
- **子参考**：autoloads / export-injection / scene-injection / service-locator / testing-with-di
- **适用场景**：GameCreator/CreatorCore 依赖管理、测试 Mock

### event-bus
- **用途**：全局事件总线——信号解耦各系统
- **子参考**：anti-patterns / testing / typed-signals
- **适用场景**：GameState 与 UI 通信、装备变化通知、战斗事件

### resource-pattern
- **用途**：Godot Resource 作为配置数据——.tres 文件驱动游戏
- **子参考**：collections / configuration-pattern / editor-integration / saving-resources / sharing-vs-unique
- **适用场景**：CharacterData/WeaponData/SkillData 全部 .tres 配置

### scene-organization
- **用途**：场景树结构组织最佳实践
- **适用场景**：编辑器面板布局、游戏场景层级

### state-machine
- **用途**：有限状态机——分层与并行状态
- **子参考**：hierarchical-and-parallel
- **适用场景**：角色战斗状态、怪物 AI 状态、UI 状态切换
