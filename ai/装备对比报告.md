## 二、最严重的问题：概率型词条被压成常驻属性（34 件）

### 2.1 问题

文档里 **72 条**词条含「有 N% 概率触发…」，其中 **37 条**的解析结果
**既没有概率、也没有触发动作**——被压成了一条**永久生效的属性加成**。

```
原文  受到伤害时，有10%概率反弹50%伤害给攻击者
解析  [104, 0.5000, true]        ← 变成永久 +50% 反伤，概率消失

原文  攻击时，有10%概率触发随机元素爆炸，造成50%攻击力的对应元素伤害
解析  [117, 0.5000, true]        ← 变成永久 +50% 元素伤害，概率与「爆炸」全丢

原文  投射物有5%概率穿透1个额外目标
解析  [103, 0.0500, true]        ← 变成 +5% 护甲穿透 —— 同词不同义

原文  闪避时有5%概率立即刷新冲刺冷却
解析  [113, 0.0500, true]        ← 变成 +5% 冷却刷新率

原文  出售装备时，有5%概率获得双倍金币
解析  [107, 0.0500, true]        ← 变成永久 +5% 金币获取
```

### 2.2 为什么这是最严重的

前一轮报告只统计「有没有解析出来」，这类问题**全部显示为「已解析」**——
报告全绿，数据是错的。而且它的后果比"没实现"更糟：

- **没实现** = 词条无效果，玩家看不出异常
- **压成常驻** = 词条以**错误的语义**永久生效，数值还可能很强

「投射物有5%概率穿透」→「+5% 护甲穿透」尤其典型：两者**共用同一个
`elem_pen` 通道**，但一个是条件触发、一个是常驻，机制完全不同。

## 三、其他问题

### 3.1 全属性被塌缩成单属性（7 件）

```
原文  每击杀一个敌人，该武器所有数值增加1%
解析  [4, 1, Stat.ATK, 0.01, 0]      ← 只有攻击力，不是「所有数值」

原文  获得被动——每击杀一个敌人，全属性增加10%，持续5秒，可无限叠加
解析  [Stat.ATK, 0.1000, true]        ← 常驻 +10% 攻击力；
                                        触发/持续5秒/无限叠加 全丢

原文  每装备一件传奇装备，全属性提高8%
解析  [Stat.ATK, 0.0800, true]
```

受影响：被腐蚀的长剑 / 记忆碎片 / 钥匙守护 / 混沌之门 / 猎杀者勋章 /
传奇共鸣 / 元素终焉

### 3.2 触发条件错（3 件）

```
原文  每击杀一个敌人回复5%最大生命值
解析  [4, 3, Stat.HP, 0.0500, 0]      ← trigger=3 是 ON_HIT（命中）
                                        应为 ON_KILL(1)——命中即回血
                                        vs 击杀才回血，完全不同
```

受影响：饮血重剑 / 吸血脉甲 / 终末裁决

## 四、根因

### 4.1 数据源不全（已修）

`equipment_spec.tsv` 原先只有 349 条而文档有 400 条——51 件从未进入流水线。
已由 `tools/extract_equipment_spec.gd` 重建（提交 `fb0ae5d3`）。

### 4.2 校验只查「有没有」，不查「对不对」

生成器此前的报告只统计「无法映射的条数」。**概率型被压成常驻**这类错误
在那种口径下**全部显示为已解析**——报告全绿，数据是错的。

现已补 `tools/verify_parse_fidelity.gd`：逐条核对**解析结果是否忠实于原文**，
判据包括触发条件、叠层上限、属性范围、数值提取、时长保留。

## 五、执行建议

| 顺序 | 工作 | 覆盖 | 说明 |
|---|---|---|---|
| 1 | **修概率型解析** | 34 件 | 判据：「有N%概率」必须产出带 `chance` 的触发型词条，不能退化成常驻属性。**收益最大且是纯 bug 修复** |
| 2 | **职业资源点系统** | 16 条 + ~10 件 | 5 职业各一套。缺口最大，且是其他机制的前置 |
| 3 | **全属性通道** | 7 件 | 新增「全属性 +N%」通道，或展开成 11 条面板属性 |
| 4 | **修触发条件** | 3 件 | 纯规则修正 |
| 5 | **技能修饰**（技能表加一列） | 9 条 | 需 `EquipmentSkills` 加 `on_cast` 列 |
| 6 | **条件型增减伤** | 8 条 | 复用已有 Trigger 机制 |
| 7 | **元素终焉 / 能量储存 / 扩散 / 陷阱 / 杂项** | 19 条 | 逐族实现 |

做完 1-4（纯修复，无新系统）可覆盖 **44 件**；做完 1-7 可覆盖全部 **81 件**。
