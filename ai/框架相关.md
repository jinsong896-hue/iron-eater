## CharacterData.gd

例如：

```gdscript
extends Resource
class_name CharacterData


@export var id:String

@export var display_name:String


# 职业
@export var class_type:String


# 基础属性
@export var base_hp:int
@export var base_attack:int
@export var base_defense:int


# 资源系统
@export var resource_type:String
@export var resource_max:int=100


# 模型
@export var model:PackedScene


# 动画
@export var animation_tree:PackedScene


# 技能列表
@export var skills:Array[SkillData]


# 被动
@export var passives:Array[PassiveData]
```

这样：

角色不是代码。

角色只是：

```
一个配置文件
```

# 五、Modifier计算器

最终属性计算：

```
Base Stats

↓

Form Modifier

↓

Equipment Modifier

↓

Devour Modifier

↓

Buff Modifier

↓

Final Stats
```


---

代码：

```gdscript
extends Node
class_name ModifierSystem



func calculate(base, modifiers):

    var result=base


    for mod in modifiers:


        match mod.operation:


            ModifierData.Operation.ADD:

                result += mod.value


            ModifierData.Operation.MULTIPLY:

                result *= (1+mod.value)


    return result

```
