### 顺带修掉的**数据层错映射**（不只是「没实现」，而是「实现错了」）

这几条比未映射更隐蔽——图鉴会显示、数据看起来正常，但语义完全不同：

| 规格原文 | 错在哪 | 修正 |
|---|---|---|
| 「获得 N% 伤害减免」 | 映射成 `elem_resist`（元素抗性）——只挡元素伤害 | 新开 `dmg_reduction`（146）通道 |
| 「护盾值 +N%」 | 同样映射成元素抗性 | 改走 `shield_power`（140） |
| 「生命低于50%时普攻变范围，造成150%伤害」 | 压成 `aoe_dmg_pct`——那是「所有范围技能+50%」的被动，且「变范围」整个没落地 | 走 `SKILL_MOD` 的普攻通道 |
| 「触发免死后获得5秒无敌」 | 映射成 `dodge +50%` | `__SKILL__` 哨兵 + 免死结算处挂无敌 |
| 「不朽壁垒」的范围反击 | 被误解析成「满血叠层回血」，层数×80% 攻击力整个丢失 | 带 `boom_pct` 的 `cheat_death` |

## 二、A 类：机制**不存在**（15 条）

### A1. 元素序列追踪 / 元素终焉（6 条）

```
元素终焉   | 技能自动轮转六元素
元素终焉   | 六种状态同时存在时触发"元素终焉"——造成600%法强全元素伤害并清空所有状态
元素终焉   | 元素终焉触发后，六种状态重新施加且持续时间刷新
元素之戒   | 连续3次不同元素后，触发元素爆炸（150%法强）
元素战镰   | 连续攻击同一目标3次后，触发元素爆炸（150%攻击力）
元素之泉法杖 | 使用不同元素技能时，下一个技能伤害+25%并附带对应元素状态
```

**现状**：`ElementDamage` 只处理**单次**攻击的元素叠层。
全项目搜 `last_element` / `elem_history` **零命中**——没有任何序列追踪。

**要建什么**：三件事
- 玩家侧「最近 N 次攻击的元素」环形缓冲（判「连续3次**不同**」）
- 「最近目标」引用（判「同一目标 3 次」）
- 「六种状态同时存在」的判定（读目标 `BuffHolder` 的六种元素层数）

**难度**：中。三个子机制可分开做。

### A2. 能量储存（3 条）

```
伤害储存护符 | 受到伤害的20%储存为"能量"（最多储存100%最大生命）
伤害储存护符 | 下次攻击释放全部储存能量
伤害储存护符 | 释放储存能量时，对周围造成50%范围伤害
```

**现状**：无任何储存/释放机制。

**要建什么**：玩家侧 `_stored_energy`（受击累加 `damage × 0.2`，
上限 `max_hp × 1.0`），下次普攻命中时转成半径 ~3 米的范围伤害并清零。

**难度**：低（纯数值累加 + 一次 AOE）。

### A3. 召唤物死亡爆炸（1 条）

```
召唤护卫胸甲 | 护卫死亡时爆炸，造成50%法强伤害
```

**现状**（2026-09-27 修正）：**信号已存在**——`EnemyBase:43` 声明了
`signal died(world_position)`，`SummonBase` 继承它并在销毁前 `emit`。
**只是没人订阅。**

> 初版写「没有死亡事件广播」是**错的**——当时只 grep 了 `summon_base.gd`
> 自己的信号声明，没往上找父类。**教训：继承链上的定义要往上查。**

**要建什么**：`SummonManager` 订阅每个召唤物的 `died` → 通知玩家结算
`on_summon_died` 类词条 → 在死亡位置生成 `DamageZone`。

**难度**：低。

### A4. 残影（1 条）

```
踏虚神靴 | 残影存在时再次冲刺可引爆所有残影，每个造成150%攻击力伤害
```

**现状**：**「残影」这个概念在项目里不存在**。
（规格里有一处 `冲刺后留下残影`，但生成器把它映射成了 `summon_dmg` 数值。）

**⚠️ 需先确认**：残影是**独立机制**（冲刺留的分身）还是**召唤物的一种**？
- 独立 → 需要新的实体类型
- 召唤物 → 复用 `SummonManager`，但要能「按来源筛选并引爆」

**难度**：中（取决于上面的答案）。

### A5. 站立 / 静止（1 条）

```
大地守护 | 站立不动1秒后获得"大地守护"（+20%减伤，+10%反伤），移动后失效
```

**现状**：`Trigger.STATIONARY`（12）**枚举已存在但零消费**。

**要建什么**：玩家侧记「静止时长」，≥1 秒挂 buff，移动则移除。

**难度**：低（与已有的 `out_of_combat` 计时同模式）。

### A6. 束缚箭（1 条）

```
巨兽猎手 | 束缚箭命中后，目标防御降低20%，持续5秒
```

**现状**：`entangle`（缠绕）词条**存在**，但没有「束缚箭」这个技能。
**且 `巨兽猎手` 的自有词条「攻击有6%概率发射束缚箭」也未实现。**

**⚠️ 需先确认**：束缚箭是装备技能，还是词条触发的投射物？

**难度**：中（要先有束缚箭）。

### A7. 周期伤害区（1 条）

```
荆棘领域 | 周围3米敌人每秒受到15%攻击力伤害
```

**现状**：`DamageZone` **完全够用**（`follow` 支持跟随玩家）。

**要建什么**：挂一个跟随玩家的 `DamageZone`，`tick_interval=1.0`。

**难度**：极低。（归 A 类只是因为「机制没接」，但成本极低。）

### A8. 减益 / 免疫（2 条）

```
大地守护 | 守护期间免疫击退
不朽壁垒 | 不朽壁垒触发后，10秒内减伤+30%且免疫控制
```

**现状**：
- ① 守护期间免疫击退：`control_immune` buff 已有 → 加「免疫击退」变体。**难度低**
- ② 不朽壁垒触发后：**依赖「免死」机制**——项目里不存在（见 §4.3）

**难度**：① 低；② 待澄清。

## 四、C 类：需先澄清（8 条）

### 4.1 「链接一名友方」的「友方」指谁？（3 条）

```
灵魂链接      | 链接期间自身获得15%减伤
生命链接护手   | 链接期间自身获得10%减伤
生命链接护符   | 链接期间自身获得5%减伤
```

**现状**：`equipment_skills.gd` 的 3 条技能**已经声明了参数**
（`link_ally: true` / `link_share_pct: 0.4` / `link_heal: true`），
但**引擎侧零消费点**——**典型的「有数据没消费」**。

本作是**单人 Roguelike**——没有队友。场上可能的"友方"只有召唤物与分身。

**需确认**：链接目标是召唤物吗？还是这个设计来自"有队友"的假设？

> **注意**：三条融合词条写的是「链接期间**自身**获得 N% 减伤」——
> 若按「自己给自己减伤」实现，不需要友方目标，最简且与原文一致。
> 但技能表的 `link_share_pct`（分担伤害）仍需一个目标。

### 4.2 陷阱系统（3 条）

```
陷阱探测器 | 触发陷阱时，有20%概率免疫伤害
陷阱探测器 | 陷阱伤害减少0.5%
陷阱探测器 | 显示附近陷阱（小地图）
```

**现状**：
- `ON_TRAP_TRIGGER`(16) 枚举已建
- `DamageZone` 有「陷阱型」注释
- `floor_environment.gd` 有「泥潭陷阱」（那是**关卡环境**）
- `EquipmentSkills` 里只有 **1 条**陷阱技能（`冰霜陷阱长弓`）

**⚠️ 关键观察**：这三条**全是「探测/免疫/减伤」**——都是**防御方**的。
说明设计里**敌方会放陷阱**，玩家靠这些词条对抗。
但目前敌人**没有**放陷阱的能力。

**需确认**：要做「敌方陷阱」吗？还是只做玩家侧？

### 4.3 「终极技能」与「免死」（2 条）

```
灵魂容器 | 释放终极技能时消耗所有灵魂，每层额外造成20%伤害
不朽壁垒 | 不朽壁垒触发后，10秒内减伤+30%且免疫控制
```

**「终极技能」**：`ClassDefs` 的形态槽位是 `UNLOCK_FLOOR := [0, 3, 6, 8, 9]`，
共 5 个形态（0=初始，4=最强）。规格里的「终极技能」**可能指形态 4 的技能**。

**「免死」**：`ON_CHEAT_DEATH` 枚举已建、钩子已写，但**触发它的机制不存在**
——项目里没有任何「受到致命伤害时免疫一次」的实现。

**需确认**：
- 「终极技能」= 形态 4 的技能？
- 「免死」要不要做？（`不朽壁垒` 的自有词条依赖它）

### 4.4 语义不明（3 条）

```
护盾强化   | 攻击力提高至60%
狂战士之怒 | 范围扩大
混沌之门   | 混沌之门触发时，额外释放一次随机效果（50%效果）
```

- **护盾强化**：同装备另一条是「护盾存在时，攻击力提高40%」。
  推测「护盾**满**时提高至 60%」？还是「护盾越高攻击越高，最高 60%」？
- **狂战士之怒**：同装备另一条是「生命低于50%时，普通攻击变为范围攻击」。
  推测是「把那个范围再扩大」→ 需要先有「普攻变范围」机制
- **混沌之门**：「混沌之门」是什么？（该装备的自有词条只有「全属性增加2%」）

这三条原文本身信息不足，**不猜**。
