# 装备筛选报告（2026-09-22）

> 来源：`ai/装备参考.txt`（390 件原始设计）+ `策划书/装备参考2.docx`（规格）
> 筛选规则由用户指定。本报告是**筛选过程的留档**，实装结果见 `EquipmentDB.CURATED_TABLE`。

## 筛选规则与结果

| 规则 | 说明 | 剔除 |
|---|---|---|
| 1 | 不能有功能重复的纯上位装备（同名跨稀有度只留一件） | 17 组 |
| 2 | 不能有不符合定位的装备（尽量调到对应稀有度） | 并入其他规则 |
| 3 | 不要机制过于复杂的（叠层 / 循环 / 多段触发） | 35 |
| 4 | 不要代码层面无法实现的 | 136 |
| 新规 | 所有职业通用（去掉职业专属） | 15 |

**390 → 188 件通过**

## 规则 4 的判据（逐项对照现有代码）

| 机制 | 为什么不可实现 |
|---|---|
| 格挡 | 玩家无格挡机制（只有闪避/无敌帧） |
| 闪避率 | 玩家无「闪避率」属性（是敌人侧的 dodge_pct） |
| 元素抗性 | 玩家无元素抗性通道（elem_resist 只在敌人侧） |
| 金币获取/出售价格 | 无对应修饰量通道 |
| 经验获取 | 游戏无经验系统（局内 Roguelike） |
| 掉落率 | 无对应通道 |
| 拾取范围 | 是常量 `PICKUP_RANGE`，非可修饰属性 |
| 召唤 | 无召唤物系统 |
| 免疫（减速/击退/控制） | 无对应免疫通道 |
| 霸体/无敌 | 只有 player 的内部状态，无装备通道 |
| 刷新冷却 | 无对应通道 |
| 沉默/恐惧/嘲讽/击飞/牵引 | 敌人 AI 无对应控制状态（仅 stun/slow/root） |
| 弹射/残影 | 无对应实现 |
